Как вести расписание и менять сайт

Инструкция для тех, кто не программирует. Почти всё делается в личном кабинете, кнопками. Файлы открывать нужно только для цен и текстов на сайте.

Что где меняется

Тема встречи, гость, описание, цена, число мест Кабинет → «Команда» → «Встречи» → «Изменить» 1 минута

Расписание, которое вы ведёте в кабинете, само появляется на сайте: в афише и в блоках «Что будет» у каждого клуба. Править для этого сайт не нужно.

Часть 1. Расписание — в кабинете

Как попасть в раздел «Команда»

  1. Откройте бота Пространства в Telegram и нажмите кнопку «Кабинет» внизу.
  2. Один раз попросите того, кто настраивал сайт, сделать вас сотрудником (шаг 8 в SETUP.md).
  3. В нижнем меню появится вкладка «Команда». Гости её не видят.

В «Команде» три вкладки:

  • Встречи — встречи выбранного дня. Стрелками ‹ › листаются дни.
  • Клиенты — поиск гостя по имени, телефону или нику в Telegram.
  • Добавить — новая встреча или сразу серия встреч.

Как завести расписание с нуля

Каждый регулярный клуб добавляется один раз с повтором на полгода. Пример для литературного клуба по понедельникам:

  1. «Команда» → «Добавить».
  2. Формат: Литературный клуб.
  3. Название или тема: можно оставить пустым, тогда будет «Литературный клуб».
  4. Дата: ближайший понедельник. Начало: 18:00.
  5. Длительность: 2 ч. Мест: 40.
  6. Повторять: Полгода.
  7. Цена разово: оставьте пустой, будет обычная (2 500 ₽).
  8. Входит в абонементы: галочка стоит.
  9. «Добавить в расписание».

Так же добавьте остальные регулярные встречи:

Сценарный клуб понедельник 20:15 1 ч 45 мин

История костюма идёт 2 раза в месяц по четвергам в 12:00. Повтор «каждую неделю» тут не подходит, поэтому добавляйте каждую встречу отдельно («Повторять: Один раз»). На месяц это две записи.

Как задать тему встречи

Например, «"Лавр" Евгения Водолазкина» для литературного клуба 28 сентября.

  1. «Команда» → «Встречи», стрелками выберите 28 сентября.
  2. У нужной встречи нажмите «Изменить».
  3. В поле Название или тема напишите тему. В поле Описание можно добавить пару предложений — гости увидят их, когда откроют встречу.
  4. Внизу выберите «Только эту» и нажмите «Сохранить».

Тема сразу появится в кабинете у гостей, в афише на сайте и в блоке «Что будет».

Как добавить специального гостя

Например, Павел Глоба, 24 октября.

  1. Если на этот день уже есть встреча «Специальный гость», откройте её через «Изменить». Если нет — «Добавить».
  2. Название или тема: Павел Глоба.
  3. Ведущий или гость: например, «Специальный гость».
  4. Описание: о чём будет встреча.
  5. Цена разово: если встреча дороже обычной, впишите цену, например 3500. Пусто — обычная цена.
  6. Входит в абонементы: снимите галочку, если по абонементу на эту встречу прийти нельзя.
  7. Мест: если ждёте больше гостей, чем обычно, поменяйте число.
  8. «Сохранить».

Блок «Специальный гость» на главной странице сайта (большая фотография с датой) меняется отдельно, в файле сайта — см. часть 3.

Как перенести время клуба на все недели вперёд

Например, литературный клуб по понедельникам теперь начинается в 18:30.

  1. Найдите ближайшую такую встречу, нажмите «Изменить».
  2. Поменяйте Начало на 18:30.
  3. Выберите «Эту и следующие» и нажмите «Сохранить».

Поменяются все следующие литературные клубы по понедельникам в 18:00. Темы, которые вы уже задали для отдельных встреч, останутся. Все, кто записан, получат в Telegram сообщение: «Встреча перенесена: было… теперь…».

Как отменить встречу

«Встречи» → нужный день → «Отменить» → «Да, отменить встречу». Всем записанным придёт сообщение. Посещения по абонементу вернутся сами. Тем, кто платил разово, деньги нужно вернуть вручную через платёжную систему: такие оплаты видны в карточке клиента.

Во время встречи

  • Нажимайте на кружок рядом с именем, когда гость пришёл: кружок станет зелёным.
  • Значок трубки — позвонить гостю.
  • Нажмите на имя, чтобы открыть карточку гостя: абонемент, последние записи, оплаты, достижения и заметка, которую видит только команда.

Продажа абонемента на месте

  1. «Клиенты» → найдите гостя. Если его нет, пусть сначала откроет бота и кабинет.
  2. Откройте карточку, выберите абонемент и месяц. Для «Одного клуба» выберите клуб.
  3. «Оплачено на месте — оформить». Абонемент включится сразу, гостю придёт сообщение.

Что гости получают сами

  • напоминание накануне встречи и за 2 часа до начала;
  • сообщение о переносе или отмене встречи;
  • сообщение, когда в полном зале освободилось место (если стояли в листе ожидания);
  • напоминание продлить абонемент за 3 дня до конца месяца и в последний день;
  • поздравление с новым достижением.

Достижения

Часть 2. Цены абонементов — файл api/config.php

Как открыть файл

  1. Зайдите в панель Руцентра → хостинг → Файловый менеджер.
  2. Откройте папку сайта, в ней папку api.
  3. Сначала скачайте копию config.php к себе на компьютер. Если что-то пойдёт не так, просто загрузите её обратно.
  4. Нажмите на config.php → «Редактировать».

Что менять

Найдите блок plans (в браузере — клавиши Ctrl + F, слово plans):

'plans' => [
    'club1' => ['name' => 'Один клуб',        'price' => 3500,  'clubs' => 1, 'weekend' => 2, 'costume' => 0, 'art' => 0],
    'clubs' => ['name' => 'Клубы и гости',    'price' => 6500,  'clubs' => 2, 'weekend' => 4, 'costume' => 0, 'art' => 0],
    'all'   => ['name' => 'Всё Пространство', 'price' => 12000, 'clubs' => 2, 'weekend' => 6, 'costume' => 2, 'art' => 4],
],
  • price — цена в рублях, без пробелов: 7000, а не 7 000.
  • weekend — сколько выходных встреч (гости и кино) входит.
  • costume — занятий по истории костюма, art — занятий рисунком.
  • name — название абонемента: меняйте только текст внутри кавычек.

Ниже в том же файле:

  • 'single_price' => 2500 — цена разового посещения;
  • 'capacity' => 40 — сколько мест ставится новым встречам.

Правила, чтобы ничего не сломать:

  • меняйте только числа и текст внутри кавычек;
  • не удаляйте кавычки ', запятые , и скобки [ ];
  • сохраните файл и откройте кабинет: если он пишет «Что-то пошло не так», верните скачанную копию.

Новые цены действуют для новых покупок. Уже купленные абонементы не меняются. Цены на сайте нужно поменять отдельно, в части 3.

Часть 3. Тексты сайта — файл index.html

Сайт — это один файл index.html в корне папки сайта.

Как открыть и поменять

  1. Панель Руцентра → Файловый менеджер → скачайте копию index.html к себе.
  2. Откройте index.html → «Редактировать». Можно и у себя на компьютере: в Блокноте или бесплатной программе Notepad++, а потом загрузить файл обратно с тем же именем.
  3. Нажмите Ctrl + F и найдите текст, который нужно поменять (таблица ниже).
  4. Поменяйте только слова между значками > и <.

Пример. Было:

<li>Москва, ул. Садовая, 12, отдельный вход</li>

Стало:

<li>Москва, ул. Большая Никитская, 5, отдельный вход</li>

Значки <li> и </li> остались на месте, поменялся только адрес.

У цен в карточках абонементов есть второе место — надпись на кнопке, например data-plan="Один клуб · 3 500 ₽ в месяц". Поменяйте цену и там, это внутри кавычек.

Что не трогать

  • всё, что внутри <script> … </script> и <style> … </style>;
  • слова на латинице вроде class="…", href="…";
  • файлы в папках api/lib и app — это программа.

Если после правки страница выглядит сломанной, загрузите обратно скачанную копию index.html.

Часть 4. Фотографии

Все фотографии лежат в папке img. Каждая в двух размерах:

  • …-s.webp — для телефона, ширина 1200 пикселей;
  • …-l.webp — для компьютера, ширина 1600–2800 пикселей.
Файл Где на сайте
hero, hero-m первый экран (hero-m — вертикальный, для телефона)
hall, hall-shelves, hall-tea, hall-screen блок «Зал»
ch-lit, ch-script, ch-guest, ch-film, ch-costume, ch-art клубы на сайте и встречи в кабинете
guest-stage блок специального гостя
d-tea, d-script, d-fabric, d-drawing, d-projector коллаж и подробности

Как заменить фото на настоящее:

  1. Откройте бесплатный сайт squoosh.app, перетащите туда фотографию.
  2. Справа выберите формат WebP, качество 80, ширину 1200 — сохраните как, например, hall-s.webp.
  3. Повторите с шириной 2400 — сохраните как hall-l.webp.
  4. Загрузите оба файла в папку img с заменой.

Имена файлов должны совпасть до буквы, тогда сайт подхватит новые фотографии сам.

Если что-то пошло не так

  • Кабинет пишет «Что-то пошло не так». Скорее всего, опечатка в config.php. Верните скачанную копию.
  • Сайт выглядит сломанным. Верните копию index.html.
  • Гостям не приходят напоминания. Проверьте, что в панели Руцентра работает планировщик задач (cron) — шаг 6 в SETUP.md.
  • Гость не видит встречу. Проверьте в «Команде», что она не отменена и дата верная. Прошедшие встречи в расписании не показываются.
