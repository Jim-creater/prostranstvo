# Как запустить сайт и кабинет по-настоящему

Инструкция для того, кто будет запускать: для вас или для помощника. Программировать не нужно, но придётся поработать в панели хостинга Руцентра и поправить один файл настроек.

Каждый шаг устроен одинаково: **что сделать → что должно получиться**. Делайте по порядку и не переходите дальше, пока не получилось.

Везде ниже `ВАШ-ДОМЕН.ru` — это адрес сайта Пространства, например `prostranstvo-club.ru`. Подставляйте свой.

**Другие инструкции:**

- [БОТ.md](БОТ.md) — бот в Telegram: проверка на телефоне сейчас и подключение при запуске;
- [ИНСТРУКЦИЯ.md](ИНСТРУКЦИЯ.md) — как вести расписание, менять цены, тексты и фото после запуска.

## Что понадобится

| Что | Зачем | Есть? |
|---|---|---|
| Хостинг с **PHP 8** и **MySQL** | Без этого не работают кабинет, бот и оплата | ❌ Сейчас тариф «Сайт 1» — в нём этого нет |
| **Домен** для Пространства | Адрес сайта, например `prostranstvo-club.ru` | ❌ `kod-chempiona.ru` занят другим сайтом |
| **SSL-сертификат** для этого домена | Адрес с `https://`. Без него Telegram не откроет кабинет | ❌ Сертификат GlobalSign привязан к `kod-chempiona.ru` |
| **Бот в Telegram** | Вход в кабинет, напоминания | ✅ @prostranstvo_msk_club_bot |
| **Платёжная система** | Оплата абонементов на сайте | ⏳ Выберем позже; пока оплата тестовая |
| **Реквизиты ИП** | Для документов о персональных данных | Есть у вас |

Пока хостинга нет, всё можно посмотреть на телефоне: [БОТ.md](БОТ.md), часть 1.

## Шаг 1. Хостинг с PHP и MySQL

**Что сделать:**

1. Зайдите в панель Руцентра → **Хостинг** → ваша услуга → **Сменить тариф**.
2. Выберите **«Сайт 2»** или старше. В них есть PHP и MySQL. По обзорам «Сайт 2» стоит около 1 000 ₽ в месяц, точную доплату покажет панель.
3. **Перед сменой** напишите в поддержку Руцентра: «Останутся ли на месте сайты, которые уже лежат на хостинге, если перейти с тарифа "Сайт 1" на "Сайт 2"?». Обычно остаются, но лучше уточнить.

**Что должно получиться:** в характеристиках тарифа у PHP и баз MySQL стоит не «Нет», а число или галочка.

## Шаг 2. Домен и сертификат

**Что сделать:**

1. Купите домен для Пространства в Руцентре (раздел «Домены»), например `prostranstvo-club.ru`.
2. Привяжите домен к хостингу: **Хостинг → Сайты → Добавить сайт**, укажите домен.
3. Подключите SSL-сертификат для нового домена. Спросите поддержку: «Как подключить бесплатный сертификат Let's Encrypt для сайта ВАШ-ДОМЕН.ru?»

**Что должно получиться:** адрес `https://ВАШ-ДОМЕН.ru` открывается в браузере, и рядом с адресом — значок замка.

## Шаг 3. Настройки сайта в панели

В панели Руцентра, в настройках нового сайта:

1. **Версия PHP** — поставьте 8.1 или новее.
2. **Базы данных → Создать базу.** Запишите на бумагу три вещи: имя базы, имя пользователя, пароль.

**Что должно получиться:** у вас на руках имя базы, пользователь и пароль.

## Шаг 4. Загрузить файлы

**Что сделать:**

1. Откройте в панели **Файловый менеджер**, зайдите в папку нового сайта. Обычно это папка `docs` внутри папки с именем домена.
2. Загрузите туда **содержимое** папки `site` из архива (не саму папку `site`, а то, что внутри).

**Что должно получиться:** в папке сайта лежат `index.html`, `privacy.html`, `consent.html` и папки `img`, `app`, `api`. Адрес `https://ВАШ-ДОМЕН.ru` показывает сайт Пространства.

## Шаг 5. Файл настроек `config.php`

Все пароли и ключи хранятся в одном файле. Он закрыт от посторонних: из браузера его не открыть.

**Что сделать:**

1. В файловом менеджере зайдите в папку `api`.
2. Сделайте копию файла `config.sample.php` и назовите её `config.php`.
3. Откройте `config.php` → «Редактировать» и заполните. Меняйте только то, что внутри кавычек `' '`:

| Строка в файле | Что вписать |
|---|---|
| `'dsn' => 'mysql:host=localhost;dbname=prostranstvo;...'` | вместо `prostranstvo` после `dbname=` — имя базы из шага 3 |
| `'user' => 'prostranstvo'` | имя пользователя базы |
| `'pass' => 'пароль-от-базы'` | пароль базы |
| `'site_url'`, `'app_url'`, `'api_url'` | замените `prostranstvo.ru` на ваш домен. `app_url` заканчивается на `/app/`, `api_url` — на `/api/` |
| `'token' => ''` | токен бота — см. [БОТ.md](БОТ.md), часть 2, шаг 1 |
| `'bot_username' => ''` | `prostranstvo_msk_club_bot` |
| `'webhook_secret' => ''` | любая длинная строка из латинских букв и цифр, 30–40 знаков. Придумайте или возьмите в генераторе паролей |
| `'cron_key' => '...'` | другая длинная строка, тоже 30–40 знаков. Запишите её: она понадобится в шагах 6, 7 и 9 |

4. Сохраните.

**Что должно получиться:** файл `config.php` сохранён. Скачайте его копию к себе и храните в надёжном месте: в нём все пароли.

**Если что-то пошло не так:** после сохранения сайт и кабинет могут написать «Что-то пошло не так». Обычно это стёртая кавычка или запятая. Откройте файл и сравните строку с `config.sample.php`.

## Шаг 6. Создать базу и расписание

Откройте в браузере по очереди. Вместо `КЛЮЧ` — ваш `cron_key` из шага 5.

1. Создать таблицы:

   ```
   https://ВАШ-ДОМЕН.ru/api/setup.php?key=КЛЮЧ&cmd=init
   ```

   **Должно появиться:** «Таблицы созданы.»

2. Добавить расписание на 8 недель вперёд, начиная с понедельника (дату поменяйте на ближайший понедельник):

   ```
   https://ВАШ-ДОМЕН.ru/api/setup.php?key=КЛЮЧ&cmd=seed&a=2026-10-05&b=8
   ```

   **Должно появиться:** «Добавлено встреч: …».

   Добавятся: пн и ср — литературный клуб в 18:00 и сценарный в 20:15; пт — сценарный в 19:30; сб — литературный в 12:00, гость в 16:00, кино в 19:30; вс — рисунок в 12:00, гость в 16:00, кино в 19:30; история костюма — 1-й и 3-й четверг в 12:00. Потом всё меняется в кабинете кнопками, см. [ИНСТРУКЦИЯ.md](ИНСТРУКЦИЯ.md).

## Шаг 7. Подключить бота

Сделайте часть 2 из [БОТ.md](БОТ.md): токен, адрес кабинета, домен и включение бота.

**Что должно получиться:** бот отвечает на `/start`, кабинет открывается в Telegram.

## Шаг 8. Планировщик задач (cron)

Планировщик раз в 15 минут запускает всё, что происходит само: напоминания о встречах, напоминание продлить абонемент, освобождение мест, поздравления с достижениями.

**Что сделать:**

1. В панели Руцентра найдите **Планировщик задач** (или «Cron»).
2. Добавьте задачу с периодом **каждые 15 минут**.
3. Что запускать — зависит от панели:
   - если просит **адрес страницы**:

     ```
     https://ВАШ-ДОМЕН.ru/api/cron.php?key=КЛЮЧ
     ```

   - если просит **команду**:

     ```
     php ~/ВАШ-ДОМЕН.ru/docs/api/cron.php
     ```

     Путь к папке сайта сверьте в файловом менеджере.

**Что должно получиться:** адрес `https://ВАШ-ДОМЕН.ru/api/cron.php?key=КЛЮЧ` в браузере показывает строку вида `{"expired":0,"r24":0,...}`. Это значит, что всё работает.

## Шаг 9. Сотрудники

**Что сделать:**

1. Каждый сотрудник один раз открывает бота, нажимает «Кабинет», проходит знакомство и указывает телефон.
2. Откройте в браузере (в конце — телефон сотрудника, только цифры, начиная с 7):

   ```
   https://ВАШ-ДОМЕН.ru/api/setup.php?key=КЛЮЧ&cmd=staff&a=79001234567
   ```

   **Должно появиться:** «Готово: … теперь сотрудник.»
3. Сотрудник закрывает и снова открывает кабинет.

**Что должно получиться:** у сотрудника внизу появилась вкладка **«Команда»**. У гостей её нет.

## Шаг 10. Чат держателей карты (по желанию)

1. Создайте в Telegram закрытую группу, например «Пространство — держатели карты».
2. Добавьте в неё бота @prostranstvo_msk_club_bot и сделайте администратором с правами **«Добавление участников»** и **«Блокировка участников»**.
3. В настройках группы создайте пригласительную ссылку с включёнными **«Заявками на вступление»**.
4. Узнайте номер группы: перешлите любое сообщение из группы боту [@getidsbot](https://t.me/getidsbot). Номер начинается с `-100`.
5. Впишите в `config.php`: ссылку — в `'members_chat_invite'`, номер — в `'members_chat_id'`.

**Что должно получиться:** бот сам пускает в чат тех, у кого есть абонемент, а 1-го числа убирает тех, кто не продлил.

## Шаг 11. Оплата

Пока в `config.php` стоит `'provider' => 'test'`, оплата условная: кнопка «Оплатить» сразу засчитывает платёж, деньги не списываются. Так можно всё проверить до подключения денег.

Когда выберете платёжную систему, её подключат здесь. Сейчас готово подключение **ЮKassa**:

1. В кабинете ЮKassa возьмите **shopId** и **секретный ключ** (раздел «Интеграция» → «Ключи API»).
2. Там же в «HTTP-уведомлениях» укажите адрес `https://ВАШ-ДОМЕН.ru/api/pay-webhook.php` и отметьте события `payment.succeeded` и `payment.canceled`.
3. Подключите отправку чеков: «Чеки от ЮKassa» или свою онлайн-кассу.
4. В `config.php` впишите `shop_id`, `secret_key` и поменяйте `'provider' => 'test'` на `'provider' => 'yookassa'`. Ставку НДС (`vat_code`) уточните у бухгалтера: `1` — без НДС.

**Проверка:** временно поставьте встрече цену 10 ₽ и запишитесь с настоящей оплатой.

## Шаг 12. Документы о персональных данных

Закон 152-ФЗ требует этого до того, как вы начнёте собирать имена и телефоны.

1. Откройте `privacy.html` и `consent.html`, замените всё в квадратных скобках `[...]`: ФИО, ИНН, ОГРНИП, адрес, почта, хостинг (Руцентр) и платёжная система.
2. Подайте уведомление в Роскомнадзор об обработке персональных данных: [pd.rkn.gov.ru](https://pd.rkn.gov.ru/). Для компаний и ИП штраф за работу без уведомления — до 300 тыс. ₽.
3. Покажите документы юристу. Отдельно спросите про Telegram: это иностранный сервис, может понадобиться уведомление о трансграничной передаче данных.

## Шаг 13. MAX (по желанию)

Пока выключено: неясно, можно ли зарегистрировать бота MAX на ИП. Если получится зарегистрировать на платформе MAX для бизнеса:

1. Впишите в `config.php`, раздел `max`: токен, ссылку на бота, `webhook_secret` и поставьте `'enabled' => true`.
2. Откройте `https://ВАШ-ДОМЕН.ru/api/setup.php?key=КЛЮЧ&cmd=max-webhook`.

В профиле кабинета у гостей появится кнопка «Подключить MAX». Входить в кабинет по-прежнему нужно через Telegram.

## Последняя проверка перед открытием

- [ ] Сайт открывается по `https://ВАШ-ДОМЕН.ru`, внизу нет надписи «Прототип», адрес и телефон — настоящие.
- [ ] Бот отвечает на `/start`.
- [ ] Новый гость проходит знакомство, покупает абонемент (в тестовом режиме), записывается — бот присылает «Вы записаны».
- [ ] Отмена больше чем за сутки возвращает посещение на абонемент.
- [ ] У сотрудника есть вкладка «Команда», он может отметить гостя.
- [ ] Планировщик работает: `cron.php?key=КЛЮЧ` показывает строку с цифрами.
- [ ] Документы заполнены, уведомление в Роскомнадзор подано.
- [ ] Оплата переключена на настоящую, и прошёл пробный платёж.

## Для программиста

- `site/api/` — PHP 8 без фреймворков: `index.php` (API кабинета), `bot.php` (Telegram), `max-bot.php`, `pay-webhook.php`, `cron.php`, `setup.php`. Правила абонементов — `lib/rules.php`, достижения — `lib/achievements.php`.
- `site/app/` — кабинет на чистом JS: `app.js`, `app.css`, `config.js`; `demo.js` — показ без сервера (`demo: true`).
- Цены и состав абонементов — `config.php`, раздел `plans`.
- GitHub Pages: `.github/workflows/pages.yml` публикует `site/` в демо-режиме при обновлении ветки `main`.
- Автотесты: `bash tests/run.sh`.
