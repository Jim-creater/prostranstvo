Бот в Telegram: проверка на телефоне и запуск

Эта инструкция — про бота @prostranstvo_msk_club_bot и кабинет, который открывается внутри Telegram.

Она из двух частей:

  • Часть 1 — проверить сейчас. 10 минут, бесплатно. Кабинет работает на примерных данных, хостинг не нужен.
  • Часть 2 — настоящий запуск. Когда будет хостинг с PHP (см. SETUP.md).

Часть 1. Проверить на телефоне сейчас

Шаг 1. Исправить адрес кабинета

  1. Откройте в Telegram @BotFather.

  2. Отправьте команду:

    /myapps

    Если BotFather её не знает, отправьте /editapp.

  3. Выберите бота @prostranstvo_msk_club_bot, потом приложение prostranstvo_msk.

  4. Нажмите Edit Web App URL (или «Изменить ссылку»).

  5. Отправьте ровно этот адрес, скопируйте его целиком:

    https://jim-creater.github.io/prostranstvo/app/

    Важно: в конце /app/. Имя бота в адрес не добавляйте.

  6. BotFather ответит, что ссылка обновлена.

Проверка: откройте эту ссылку в браузере телефона. Должен открыться кабинет Пространства, а не 404.

Шаг 2. Кнопка «Кабинет» в чате с ботом (по желанию)

Чтобы кабинет открывался кнопкой рядом с полем ввода:

  1. В @BotFather отправьте /mybots → выберите @prostranstvo_msk_club_bot → Bot Settings → Menu Button.

  2. Отправьте адрес:

    https://jim-creater.github.io/prostranstvo/app/

  3. Отправьте название кнопки:

    Кабинет

Шаг 3. Открыть на телефоне

Откройте на телефоне ссылку:

https://t.me/prostranstvo_msk_club_bot/prostranstvo_msk

Или откройте чат с ботом и нажмите кнопку «Кабинет» (если сделали шаг 2).

Кабинет откроется как у нового гостя и поздоровается по вашему имени из Telegram.

Что проверить

Пройдите путь клиента:

  1. Знакомство. Нажмите «Взять номер из Telegram» (телефон подставится сам), поставьте галочку согласия, «Продолжить».
  2. Покупка абонемента. «Выбрать абонемент» → «Клубы и гости» → «Оплатить 6 500 ₽» → «Оплатить». Оплата здесь условная, деньги не списываются.
  3. Запись. «Выбрать встречи» → нажмите на встречу → «Записаться».
  4. Мои записи. Вкладка «Записи»: встреча там, её можно отменить.
  5. Раздел команды. Нажмите наверху «Демо · гость» — станет «Демо · команда», и появится вкладка «Команда». Нажмите ещё раз, чтобы вернуться к виду гостя.

Чего в проверке не будет — и это нормально

  • Бот не отвечает на сообщения и на /start. Боту нужен сервер, а его пока нет.
  • Напоминания и сообщения от бота не приходят — по той же причине.
  • Всё сбрасывается, когда закрываете кабинет: данные примерные и нигде не хранятся.
  • Встречи, гости и другие клиенты — примеры.

Частые ошибки

Что видно Почему Как исправить
404 File not found при открытии кабинета В Web App URL неправильный адрес Шаг 1: адрес должен быть https://jim-creater.github.io/prostranstvo/app/
Invalid short name Вписали ссылку t.me/... вместо короткого имени Отправьте только слово: латиница, цифры, _, от 3 до 30 знаков. Например, prostranstvo_msk
Sorry, the image dimensions are invalid. Must be 640x360 Картинка не того размера Нужна картинка ровно 640 × 360 пикселей
Бот молчит на /start Нет сервера Это нормально до части 2
Кабинет открывается, но пустой или «Нет связи» Плохой интернет или старая версия Telegram Обновите Telegram, откройте ещё раз
Токен попал в чужие руки (показали на скриншоте, отправили в чат) Кто знает токен, управляет ботом В @BotFather: /revoke → выберите бота. Старый токен перестанет работать, BotFather выдаст новый

Токен — как пароль. Не отправляйте его в чаты, не вставляйте на сайт и в GitHub. Он нужен только в одном месте — в файле config.php на хостинге (часть 2).

Часть 2. Настоящий запуск

Делается, когда уже готово всё из SETUP.md: хостинг с PHP, домен, файлы загружены. Ниже вместо ВАШ-ДОМЕН.ru пишите свой адрес, например prostranstvo-club.ru.

Шаг 1. Токен — в config.php

  1. Токен лежит в чате с @BotFather, в сообщении после создания бота. Если не можете найти: /mybots → бот → API Token.

  2. Вставьте его в файл api/config.php на хостинге, в строку:

    'token' => 'СЮДА-ТОКЕН',

    Токен — внутри кавычек, кавычки не удаляйте.

  3. В той же части файла заполните:

    'bot_username' => 'prostranstvo_msk_club_bot',

Шаг 2. Адрес кабинета — на свой домен

В @BotFather: /myapps → бот → prostranstvo_msk → Edit Web App URL → отправьте:

https://ВАШ-ДОМЕН.ru/app/

Шаг 3. Домен для кнопки входа на сайте

В @BotFather: /setdomain → выберите бота → отправьте:

ВАШ-ДОМЕН.ru

Без https:// и без / в конце.

Шаг 4. Включить бота

Откройте в браузере (вместо КЛЮЧ — ваш cron_key из config.php):

https://ВАШ-ДОМЕН.ru/api/setup.php?key=КЛЮЧ&cmd=webhook

На странице должно быть три ответа со словом true. После этого бот начнёт отвечать на /start, а кнопка «Кабинет» в чате с ботом сама поменяет адрес на ваш домен.

Шаг 5. Проверить

  1. Напишите боту /start — он должен ответить приветствием и кнопкой «Открыть кабинет».
  2. Откройте кабинет, пройдите знакомство, запишитесь на встречу. Бот должен прислать «Вы записаны».
  3. Откройте на компьютере https://ВАШ-ДОМЕН.ru/app/ — должна появиться кнопка «Войти через Telegram».

Если на шаге 4 вместо true ошибка — проверьте токен в config.php (без пробелов, целиком) и что сайт открывается по https://.
