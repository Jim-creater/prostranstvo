# Пространство — памятка для работы над проектом

Сайт и личный кабинет для «Пространства» (Москва): один зал ~60 м² без окон, отдельный вход, 40 мест. Владелец — ИП, не программист: объяснять по-русски, простыми словами, без жаргона.

## Что где

- `site/` — всё, что загружается на хостинг целиком.
  - `index.html` — сайт (светлый, GSAP + ScrollTrigger + Lenis). Афиша и блоки «Что будет» берут встречи из API, если он доступен, иначе показывают примеры из массива `EVENTS`.
  - `app/` — личный кабинет, чистый JS без сборки: `index.html`, `app.css`, `app.js`, `config.js`. Тот же код работает как Telegram Mini App. `demo.js` — демо без сервера (`demo: true` в `config.js`; `app.js` подгружает его сам).
  - `api/` — PHP 8 + MySQL без фреймворков. `index.php` (роутер `?r=`), `bot.php` (Telegram), `max-bot.php`, `pay-webhook.php` (ЮKassa), `cron.php` (каждые 15 минут), `setup.php` (init, seed, webhook, staff). Правила — `lib/rules.php`, достижения — `lib/achievements.php`.
  - `privacy.html`, `consent.html` — шаблоны документов по 152-ФЗ, поля `[в скобках]` не заполнены.
- `docs/SETUP.md` — запуск на хостинге Руцентра; `docs/ИНСТРУКЦИЯ.md` — методичка для владельца. У обеих есть `.html`-копии: после правки `.md` обновить и их.
- `tests/` — автотесты API на SQLite.

## Команды

- Тесты: `bash tests/run.sh` (нужен PHP 8 с pdo_sqlite и curl). Сейчас 47 проверок, все проходят. Запускать после любой правки `site/api/`.
- Посмотреть кабинет без сервера: поставить `demo: true` в `site/app/config.js` и открыть `site/app/index.html` в браузере. **Не коммитить `demo: true`.**
- Локальный сервер с API: `PR_CONFIG=путь/к/config.php php -S 127.0.0.1:8099 -t site`, конфиг по образцу `tests/config.test.php` (SQLite, `dev_login => true`, `provider => test`).

## Правила

- Секреты только в `site/api/config.php`, он в `.gitignore`. Никогда не коммитить.
- Гость и команда разделены по правам: вкладка «Команда» видна только при `is_staff`, а каждый `staff/*` запрос на сервере проверяет `require_staff()` (403 для гостей). Новые служебные запросы — только через `require_staff()`.
- Бизнес-правила: абонемент на календарный месяц, посещения сгорают, заморозки нет; отмена без списания не позже чем за 24 часа; разовое посещение 2 500 ₽; 40 мест; неоплаченная бронь держится 30 минут; лист ожидания.
- Абонементы (цены и состав — `config.php`, раздел `plans`; значения по умолчанию в `rules.php`): «Один клуб» 3 500 ₽ (клуб на выбор + 2 выходные проходки), «Клубы и гости» 6 500 ₽ (оба клуба + 4), «Всё Пространство» 12 000 ₽ (оба клуба + 6 + история костюма 2 + рисунок 4). Во всех — чат держателей карты.
- Расписание: пн и ср литературный клуб 18:00 и сценарный 20:15 (подтверждено владельцем), пт сценарный 19:30, сб лит 12:00 / гость 16:00 / кино 19:30, вс рисунок 12:00 / гость 16:00 / кино 19:30, история костюма 1-й и 3-й чт в 12:00. Павел Глоба (фамилия — Глоба) 24 октября.
- Интерфейс и тексты — на русском, коротко и по делу; вёрстка сначала для телефона. Цвета: фон `#F6F3EE`, текст `#1A1714`, акцент `#C2531E`; форматы: lit `#4E7A3B`, script `#3457A6`, guest/film `#B4462F`, costume `#8E3F7C`, art `#94650F`. Шрифты Cormorant Garamond, Onest, JetBrains Mono. На фото — люди славянской внешности.
- Картинки в `site/img/`: WebP в двух размерах, `-s` (1200 px) и `-l`.

## Что ещё не решено

1. **Хостинг.** У владельца тариф Руцентра «Сайт 1» — без PHP и MySQL. Для кабинета нужен «Сайт 2» или выше, свой домен для Пространства и SSL для него (сертификат GlobalSign куплен для kod-chempiona.ru).
2. **Оплата.** Платёжная система не выбрана. Сейчас `provider => test`, реализована ЮKassa (`lib/payments.php`); при другой системе — добавить провайдера там же.
3. **Telegram-бот** ещё не создан (BotFather: `/newbot`, `/setdomain`, `/newapp`).
4. **MAX** выключен: неясно, можно ли зарегистрировать бота на ИП.
5. **152-ФЗ:** заполнить реквизиты ИП в `privacy.html` и `consent.html`, подать уведомление в Роскомнадзор.
6. На сайте в подвале надпись «Прототип…», адрес и телефон — примеры.
